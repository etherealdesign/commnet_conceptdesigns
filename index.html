For the team

Run locally

Every build above also opens straight from disk — double-click its index.html. To work on a React build, run its dev server from source/, then rebuild its copy in sites/.

./start.shServe this hub and every build at 127.0.0.1:8080
./start.sh dev v1-reactHot-reload dev server — also v3, v4, v5, teleiostec, or all
./start.sh build allRebuild the self-contained copies in sites/ from source/
./start.sh statusWhich servers are running, and on which port
./start.sh stopStop every server this project started
